# Excel Assignment 1 – Data Exploration

## 📌 Project Overview
This project demonstrates my foundational Microsoft Excel skills through a data exploration assignment. The objective is to analyze a product dataset using Excel formulas and functions to calculate key statistics, categorize product prices, perform conditional calculations, and extract information from Product IDs.

This assignment is part of my Data Analyst learning journey and helps me develop practical skills in data analysis and spreadsheet management.

## 🎯 Objectives
- Explore and analyze a product dataset using Excel.
- Calculate basic statistical measures using built-in functions.
- Categorize products based on their price using logical functions.
- Perform conditional calculations using SUMIF and COUNTIF.
- Extract specific information from Product IDs using text functions.
- Practice organizing raw data into a structured Excel table.

## 🛠️ Tools Used
- **Microsoft Excel 2016**
- Excel formulas and functions
- Structured tables and data formatting

## 📊 Tasks Completed

### 1. Basic Data Exploration
- Converted the raw dataset into an Excel table named `Sales_Data`.
- Calculated the total product price using the SUM function.
- Counted the number of products using the COUNT function.
- Calculated the average product price using the AVERAGE function.

### 2. Minimum and Maximum Values
- Identified the minimum product price using the MIN function.
- Identified the maximum product price using the MAX function.

### 3. Logical Function – IF
Created a new column named `Price Range` to categorize products based on their prices:
- **High Price:** Price greater than or equal to $500.
- **Standard Price:** Price less than $500.

### 4. Conditional Functions – SUMIF and COUNTIF
- Used SUMIF to calculate the total price of products in the Electronics category.
- Used COUNTIF to count products priced below $100.

### 5. Text Functions – LEFT, RIGHT, and MID
Extracted specific information from the Product ID column:
- **Day:** Extracted the first two characters using LEFT.
- **Country Code:** Extracted the last two characters using RIGHT.
- **Month:** Extracted characters four to six using MID.
